# 验证结果与覆盖范围

这是几项有限范围的仿真实践记录，不是统一的算法排行榜。各任务的奖励、训练环境数与指标定义不同，不能横向比较奖励数值。

## G1：羽毛球风格动作跟踪

- 数据路径：视频 → GVHMR → GMR → 参考动作 → BeyondMimic。
- 模型：`model_4493`；曲线覆盖末期 500 轮（3994–4493），不是从零训练的完整曲线。
- 固定起点：参考第 40 帧；连续验证 236 帧（50 Hz，4.72 秒）。
- 首次终止：无；最大 anchor 高度误差 0.0503 m、姿态误差 15.61°。
- 足底接触力 >1 N：左 225/236 帧，右 213/236 帧。
- 参考动作复用 GMR 的逐帧落地处理，调整 root 高度，不修改关节轨迹。

训练使用 GPU PhysX，最终记录使用 CPU PhysX 恢复路径：当时 Docker/WSL 图形互操作失效，恢复运行保留物理、碰撞、终止与策略。不能把两种运行路径当成完全相同的 GPU 复验。原始范围见 [验收 JSON](../evidence/badminton_acceptance.json) 和 [旧仓库证据](https://github.com/jkl-ddl/gvhmr-gmr-beyondmimic-reproducible/tree/main/evidence/badminton_v2_final)。

## T800：行走与自然转向

采用同伴交付的12段行走模型作warm-start，复用SUZ的SMP门控任务奖励和MjLab足部奖励。本机Docker的512环境试验不是统一服务器的4096环境正式训练，也不是本人从零训练30000轮。

最终选定 `model_36991`。先修复walk12原始EE契约：左右踝、`LINK_BASE`、左右`LINK_ELBOW_YAW`，不混用head/waist prior。数据、prior权重、关节/PD、物理和失败阈值不变。随后仅复用已有公式调参：upright=-0.30、肩部posture=0.003、task×SMP总权重2.0、速度误差scale=2.0、SMP scale=6.0、速度/朝向比例75/25、slip=-0.10、foot-site目标0.16m。这些是本次实测配置，不是上游默认或分别证明的因果结论。T800接触时site约高0.064m，0.16m不是足底抬高16cm。

### 固定0.75m/s：原直行门槛通过

原评估器固定+x、0.75m/s、500步、seed42，原失败条件保留，actor指令最大误差0。真实接触而非高度代理：

| 指标 | 实际结果 | 原约定门槛 |
| --- | ---: | ---: |
| 连续步数 / 首次终止 | 500 / 无 | 500 / 无 |
| 实际投影均速 | 0.738443m/s | 合理跟踪0.75m/s |
| 单脚支撑 | 89.6% | >40% |
| 左右脚高度相关 | -0.813868 | <0.2 |
| 左/右接触脚滑 | 0.088346 / 0.102733m/s | 每脚<0.11m/s |
| 左/右抬脚P95 | 0.081687 / 0.092253m | 每脚>0.08m |

500帧全部实际查看，启动前倾保留，没有摔倒或reset拼接，XML静态关节限位超出0。前向均速偏差不能代替逐步二维速度误差；该回放逐步二维速度误差范数均值仍为0.195919m/s。上述门槛是本项目原先约定值，不称SUZ或MjLab官方标准。[指标](../evidence/steering_fixed075_metrics.json) · [10秒视频](../media/steering_fixed075.mp4)。

### 五段指令：连续自然转向

seed42、1环境、50Hz，五段各200步，切换用50步（1秒）过渡。每步推理前刷新actor指令、禁止验收时随机重采样，首次失败后不拼接auto-reset状态。主视频全部1000帧/16页排图及0/450/650/850放大帧已实际查看，清晰交替、连续转向、地面可见，静态XML关节限位超出0。

| 世界坐标方向 | 目标速度m/s | 主视频全段均速m/s | 双脚同时接触 | 终止数 |
| --- | ---: | ---: | ---: | ---: |
| +x | 0.50 | 0.619 | 14.5% | 0 |
| +x | 1.00 | 0.772 | 8.0% | 0 |
| +y | 0.75 | 0.612 | 12.0% | 0 |
| -x | 0.75 | 0.575 | 16.0% | 0 |
| -y | 0.75 | 0.518 | 12.5% | 0 |

分段均值包含完整切换过程。`backward_0.75`是历史标签，实际指-x行进并转身朝向目标，不是背向运动的倒走。各段单脚支撑84%–92%，脚高相关-0.68至-0.86；直行躯干前倾均值10.16°/8.79°、转向7.43°–7.86°。启动首帧root pitch约25.34°，没有裁掉。

同一入口再执行seed42重复和seed43回放，均1000步无终止、actor指令误差0。三次转向全段均速约0.465–0.613m/s；各转向段最后100步分别为0.709/0.683/0.670、0.709/0.680/0.655、0.730/0.664/0.563m/s。后100步只是补充，不能替代全段结果。记录见[seed42重复](../evidence/steering_replay2_seed42.json)、[seed43](../evidence/steering_replay3_seed43.json)。

主视频各段真实接触脚滑均值约0.082–0.132m/s、抬脚P95约0.0737–0.0954m。**转向视频没有逐段通过全部严格足部门槛**：切换时仍有pivot/脚滑、速度损失，低速有超调，高速有欠速。固定直行通过不等于所有转向、随机起点或精准导航收敛；当前完成范围是平地、窄速度、平滑指令的仿真行走/自然转向实践，不含急转、障碍规划或sim2real。

### 训练曲线与实际收敛证据

所选链共6900次真实记录更新，其中历史续训400次、本次质量修复6500次；8个续训接缝重复标签，CSV为30100–36991的6892个唯一标签。被放弃的强肩部、同配置退化、task4和主动中止ws4分支不混入最终曲线，原日志另存。当前slip10末期相邻100轮reward约0.08821→0.08642、episode长度236.36→233.76、slip日志0.14690→0.14710，接近平台而非持续改善。只有结合固定直行门槛、三次完整回放及全帧检查，才支持本次有界实践收尾；这些训练日志本身不能证明正常行走。

`Metrics/steering/error_vel_xy`与`error_face`按上游定义累计误差后除以命令最大重采样步数，并非每个episode逐步均值，episode长度也会影响它们。奖励权重改变前后不能直接比较奖励绝对值；曲线按配置接缝分段平滑，不造误差带。

### 已纠正问题与恢复边界

历史33495线上使用腰/腕，而walk12数据/prior使用base/肘，55维相同不代表语义一致。固定真实轨迹和噪声、只恢复原EE定义，raw SMP均值由0.052–0.063降至0.025–0.037；256个参考尾帧正确FK最大EE距离约1.1e-6m。[旧映射](../evidence/steering_prior_support_wrong_ee.json) · [正确映射](../evidence/steering_prior_support_walk12_ee.json)。修复训练与所有新验收显式使用`--prior-ee-contract walk12`；默认configured只保留历史模型复现。

旧33495线上复跑末段0.223/0.394m/s，未被删掉或冒充当前模型结果；[历史第一次](../evidence/steering_restore_replay1.json) · [历史第二次](../evidence/steering_restore_replay2.json)。新模型的下载恢复结果在私有恢复库单独记录。上游[MjLab FAQ](https://mujocolab.github.io/mjlab/v1.1.1/source/faq.html#why-aren-t-my-training-runs-reproducible-even-with-a-fixed-seed)说明GPU仿真不保证固定seed逐字节确定；不能将所有模型误差归咎于这一限制。

脚滑为真实接触期间足底site水平速度；抬脚为site地形高度相对该段最低值的P95。`foot_separation_command_p95_m`是两脚沿指令方向的间距，不是完整一步的步长。定义见[评估脚本](../code/eval_t800_steering.py)和[主视频实测指标](../evidence/steering_metrics.json)。状态重渲染仅换外观、光照和地面，没有改策略或物理。

## T800：历史目标速度响应补充

这是同伴交付的行走基线 `model_29999`，不是转向模型。50 Hz，随机种子 20260827，每 125 步切换一次，共 1000 步。命令序列 2.0→1.0→1.5→2.5→3.0→1.5→2.0→2.5 m/s。

剔除每段前 25 步后，目标/实际速度相关系数约 0.890，稳态 MAE 约 0.260 m/s。存在低速切换超调、高速欠速；高相关不表示每个速度都精确跟踪。详见 [分段数据](../evidence/speed_response_segments.csv)。

完整1000帧已查看，未裁剪启动段；第5、6、10–15帧存在最大0.092772rad的XML静态关节限位超出。此记录保留为历史速度试验，不标为当前行走/转向质量验收通过，也不将相同状态重渲染说成解决了策略问题。

## T800：庆祝动作

- 动作：EngineAI 官方 `dance_t800`，不是自创数据。
- 本机 Windows Native Isaac Sim：1024 环境、seed42、20,000 轮；选定 `model_19999`。
- 最后 100 轮记录均值：reward 31.37、episode length 491.27 控制步、身体位置误差 0.0694 m。
- 固定第 0 帧回放完成 1054 帧 / 21.08 秒；原 anchor/姿态/EE 失败终止均保留，首次终止为空。
- 平均身体位置误差约 0.0538 m；关节误差日志为 25 关节差值的 L2 范数，不能解释为“每个关节偏差约 0.8 rad”。

旧展示导出曾关闭三个失败终止项，不作为此次通过证据。本次重置后刷新了相同参考帧的相对身体缓存，解决 RSL 包装器再次 reset 造成的首帧假终止；没有修改失败公式或阈值。为了容纳整个动作，仅延长 time-out 时域；随机扰动和观测噪声关闭。

此次视频使用通过验证的真实策略状态重新渲染。地面和外观用于展示，策略验证仍发生在 Isaac Sim，而不是 MuJoCo 物理中重新控制机器人。

## T800：快速出拳（挑衅演示）

动作来自 G1 Moves `M_Move7 / Rapid Punch`，通过现有 G1→T800 工具修正关节数、肘部方向和前臂中立位，再使用 EngineAI tracking 训练。完整回放、选定模型与训练覆盖以 `evidence/taunt_acceptance.json`、`evidence/taunt_training.csv` 为准。

旧的无完整状态观测模型虽然完成整段，却有约2.26m的最大全局位置误差。最终采用官方 `Tracking-Flat-T800-v0`（actor140/critic275维），从零2000轮，然后三次各追加2000轮，1024环境、seed42；依次复用官方action-rate项（-0.03）与全局anchor位置奖励（weight2.0、std0.45）。参考数据、PD、物理与失败阈值不变。最终 `model_7996` 完成第0–1189帧 / 23.8秒，首次终止为空；anchor/EE高度阈值仍为0.35m，未关闭失败项。

全局anchor平均/最大位置误差0.168/0.435m，上一同配置候选5997为0.236/0.901m；相对身体平均误差0.116m，25关节误差L2均值1.092rad。XML静态诊断最大关节限位超出约0.000365rad。1190帧全部解码并逐页查看19页连续排图，出拳、转身、踢腿与恢复均可见，无摔倒或reset拼接。原失败项主要约束高度，位置残差另行报告；不把存活或这些数值包装成精确轨迹跟踪、力矩安全或实机可靠性。

曲线仅接入所选完整状态训练链：0–1999、1999–3998、3998–5997、5997–7996。共8000次实际更新，接缝复用三个迭代标签，因此CSV为7997个唯一标签；重复标签保留后一次run的数据，配置边界不跨段平滑。旧的Wo模型训练不混入该链，奖励权重改变前后不直接比较奖励绝对值。末期相邻两个100轮窗口，episode长度约430.9→430.6、25关节L2误差约1.259→1.263，趋于平稳；这与完整回放共同支持本次有限动作展示收尾，不代表所有随机起点已通过。动作和恢复源码来自线上重新下载的包，运行库复用已有Native Isaac安装；没有把它称作全新机器安装验证。

数据重定向属于直接关节映射与高度偏移，不宣称实现了接触约束 IK。模型回放与数据 FK 都使用 T800；单个固定起点成功不等于任意扰动或实机稳定性。

## 共通边界

所有结果为有限、单种子仿真实验。没有实机测试、障碍感知、全局路径规划或比赛成绩；没有把参考轨迹回放当作学到的策略，也没有将持续存活自动判定为正常行走。MP4 的 SHA256、图表覆盖范围和版本记录保存在 [产物索引](../evidence/artifact_index.json)，全部帧解码及实际视觉检查的记录见 [全帧检查](../evidence/frame_review/)。
