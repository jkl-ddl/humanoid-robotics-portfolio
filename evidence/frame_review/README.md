# 最终视频的逐帧检查

每份 JSON 记录视频 SHA256、预期/实际解码帧数、连续排图覆盖范围、遥测异常候选与实际视觉检查结论。不是只查看均匀抽取的十几帧：最终视频的每一帧都进入连续排图，并逐页查看；重点转身、踢腿、动作切换另结合同帧遥测判断。

公开仅保存结论和索引。完整连续排图、逐帧CSV与匹配策略状态在私有恢复包；排图也可由完整MP4重新生成。静态XML限位/FK检查不能证明力矩安全或真实接触，也不代替原模拟器的失败条件。

通过指这次有限仿真记录可展示，不表示随机扰动、全部起点、精准导航或实机可靠性。补充变速视频仍保留初始短暂关节限位超出，不能作为零限位违例的证明。

当前转向36991的20秒视频全部1000帧已查看，另有同模型固定0.75m/s的10秒/500帧检查。后者通过原直行步态门槛；前者仍保留转向过渡的欠速/脚滑，两个结论不混同。
